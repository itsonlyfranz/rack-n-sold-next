# Capstone documentation — Rack N Sold

This folder contains capstone-ready documentation for the Rack N Sold marketplace: seller mint and OpenSea listing flows, buyer purchases on OpenSea, admin approvals, blockchain mint API reference, and an end-user manual.

## Contents

| Document | Description |
|----------|-------------|
| [Seller: upload, mint, list on OpenSea](./seller-upload-mint-list-opensea.md) | How a seller uploads artwork, requests minting, gets an NFT on Polygon, and requests listing on OpenSea. |
| [Buyer: purchase on OpenSea](./buyer-purchase-opensea.md) | How a buyer completes a purchase using OpenSea (wallet, network, checkout). |
| [Admin: approve or reject mint and listing](./admin-approve-mint-and-listing.md) | Admin dashboard, mint approvals, sell/listing approvals, and what happens in the database. |
| [API: blockchain minting](./api-blockchain-minting.md) | HTTP endpoints and payloads for mint-related server and client flows. |
| [User manual](./user-manual.md) | Roles, sign-in, navigation, and step-by-step tasks for typical users. |
